# Home Lab

This repository documents my hands-on IT and cybersecurity home lab projects.

I use this lab to build practical experience with:

- Windows and Linux
- Networking and TCP/IP
- DNS and DHCP
- Firewalls and pfSense
- Virtual machines
- Wireshark and Nmap
- Troubleshooting
- System administration
- Cybersecurity fundamentals

## Purpose

My goal is to strengthen my troubleshooting, networking, system administration, and security skills through practical projects.

Each project will document:

- The objective
- The environment
- Tools used
- Configuration steps
- Problems encountered
- Troubleshooting process
- Resolution
- What I learned
